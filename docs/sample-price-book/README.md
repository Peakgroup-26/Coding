# Sample price book (not Peak's prices)

Made-up prices for trying the import and pricing screens. Every code and description starts
with SAMPLE so it can't be mistaken for real data. Import them on the Price books page:
`items.csv` as a price list, `prebuilds.csv` as prebuilds and `rates.csv` as labour rates, then
set SAMPLE-PLUMB as the default labour rate.

The columns use Simpro-style headings (Part Number, Trade Price, Labour Time, Charge Out Rate).
Prebuilds are in the "long" layout Simpro exports: the prebuild code repeats on one row per component.
